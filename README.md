## Reproduce (CPU only, Python 3.11, ~4-6 h on 4 threads)
```powershell
pip install -r requirements.txt          # torch/torchvision CPU wheels
$env:ROLL_NO = "M26CSA015"                # default already set in common.py
python make_split.py                      # downloads CIFAR10, writes split.npz (stratified 45k/5k)
./run_all.ps1                             # q1.py q2.py q3.py q4.py, logs in logs/
python figs.py                            # figures into figs/
python build_report.py                    # report/report.pdf from results/ and figs/
```
Note: `results/q4_pair_images.npz` (needed by `figs.py`) is regenerated by `q4.py`; `data/` and `ckpt/` are not committed.
Every training run is cached in `results/runs/*.json` and `ckpt/`, so re-running resumes.

## Files
* `common.py` – data/split, models (MLP, CNN), transforms, training loop, calibration metrics. First introduced in Q1.
* `q1.py` – Q1(a) inductive bias vs capacity; Q1(b) memorisation with label noise.
* `q2.py` – Q2 CNN vs MLP, pixel permutation, block shuffle; reuses the Q1 models/runs for the clean condition.
* `q3.py` – Q3 autoencoders (bottleneck 16/64/256), denoising AE, linear probes. Reuses the Q1/Q2 clean CNN as classifier.
* `q4.py` – Q4 SVM sweep, hard pairs, clustering on the Q3-selected encoder latent.
* `figs.py` – all figures. `results/` summaries (json), `logs/` final logs, `split.npz` saved split.

## Rules followed
Validation set (5k) is used only for lr / kernel / C / model selection; test is evaluated once after selection.
No pretrained networks, external data, or architecture search.
